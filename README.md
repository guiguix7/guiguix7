## 👨‍💻 A little about me

I'm a Systems Development student at **ETEC Martinho Di Ciero**, from Brazil. I enjoy turning ideas into working software, understanding how things fit together, and learning by building, debugging, and improving real projects.

**Web development is my main focus right now** — especially interfaces, applications, APIs, and the connection between frontend, backend, and databases. I also like exploring the bigger picture: how software interacts with security, data, AI, finance, and creative work.

I'm curious by nature, so my interests go beyond one language or framework. I don't claim to master every field listed here; some are technologies I use in projects, while others are subjects I want to explore step by step.

## 🧭 What I'm focused on

- Building web interfaces and applications with JavaScript, TypeScript, and React.
- Learning more about backend development, APIs, databases, and full-stack architecture.
- Practicing debugging and making projects clearer, more useful, and easier to maintain.
- Exploring mobile development with Flutter and Dart.
- Understanding the fundamentals behind performance, privacy, and secure software.

## 🧪 Selected projects

### [Orva — Personal Organization App](https://github.com/guiguix7/Orva)
A Flutter application for organizing goals, checklists, routines, hobbies, notes, and a diary. It prioritizes **offline use and local data storage**.

**Built with:** Flutter · Dart · Riverpod · Drift · SQLite

### [Drazyx — Artist Website](https://github.com/guiguix7/Drazyx)
A website for an independent music artist, bringing together music, releases, beats, biography, services, and contact. This project connects two of my interests: **software development and music**.

**Built with:** React · TypeScript · Vite · Tailwind CSS · React Router · Supabase

### [EasyVan — Van Transportation Management](https://github.com/guiguix7/EasyVan)
A collaborative ASP.NET Core MVC project for organizing van transportation. The documented work includes user registration and persistence, form validation, user CRUD operations, and search and filters for van listings. Some features are still in development.

**Built with:** C# · ASP.NET Core MVC · Entity Framework Core · SQLite · Bootstrap

### [Personal Portfolio](https://github.com/guiguix7/Landing-Page)
My own portfolio site, built to present my profile, technologies, projects, education, and contact information. It includes responsive layouts, interactive technology details, and Portuguese/English content.

**Built with:** HTML · CSS · JavaScript
