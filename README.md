## 🔭 What I want to explore next

I like connecting programming with other subjects. These are areas I'm interested in learning more deeply:

- **Full-stack development** — understanding the whole journey from user interface to APIs, databases, deployment, and maintenance.
- **Cybersecurity** — secure coding, authentication, privacy, threat modeling, and learning how to build safer applications.
- **Data & analytics** — SQL, data modeling, visualization, and using data to understand real problems.
- **Artificial intelligence** — practical AI integrations, useful applications, and learning how these systems work.
- **Finance & technology** — financial literacy, economic systems, and the ways software can help people understand and manage information.
- **Music & creative technology** — music production, digital experiences, and the intersection between sound, creativity, and code.
- **Programming fundamentals** — algorithms, problem-solving, debugging, testing, and writing code that is easier to understand.

I don't expect to learn everything at once. My approach is to stay curious, study the fundamentals, build small experiments, and turn what I learn into projects.
